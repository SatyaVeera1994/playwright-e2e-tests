# ⭐ 1. Playwright Locators

### English

- Locator is used to find web elements.
- Preferred locators:
  - `getByRole()`
  - `getByLabel()`
  - `getByText()`
  - `getByPlaceholder()`
  - `locator()`

### Telugu

- **Locator అంటే Web Element ని గుర్తించడానికి ఉపయోగిస్తాము.**
- **Best Practice → getByRole() ఉపయోగించాలి.**

**Example**

```ts
await page.getByRole("button", { name: "Login" }).click();
```

# ⭐ 5. JavaScript Revision

## let

Used for variable declaration.

```javascript
let age = 25;
```

## const

Cannot be reassigned.

```javascript
const name = "Satya";
```

## Async/Await

```javascript
const title = await page.title();
```

## Promise

Promise handles asynchronous operations.

```javascript
fetch().then();
```

### Telugu

- **let → value change చేయవచ్చు**
- **const → value change చేయలేము**
- **async/await → asynchronous operations handle చేస్తుంది**
- **Promise → async operation result ని represent చేస్తుంది**

# ⭐ Interview Tips

### ✅ Do

- Speak slowly and clearly.
- Answer in **2–4 sentences**.
- Give a **real project example** whenever possible.
- If asked to write code, explain while writing.

### ❌ Don't

- Don't memorize long definitions.
- Don't interrupt the interviewer.
- Don't guess if you don't know.

If you don't know an answer:

**English:**

> "I haven't worked on this feature directly, but I understand the concept and I'm confident I can learn it quickly."

**Telugu:**

> **"ఈ feature పై direct hands-on experience లేదు. కానీ concept తెలుసు. అవసరమైతే త్వరగా నేర్చుకోగలను."**
