# Module 1 – Topic 6: Functions Basics

## 1. What is a Function?

> A function is a reusable block of code that performs a specific task.

ఒక particular పని చేయడానికి రాసిన code block ని **function** అంటాం.



### Q2. What is a parameter?

> "A parameter is a variable defined in the function declaration that receives input."

Example:

```javascript
function add(a, b) {
}
```

`a` and `b` are parameters.

---

### Q3. What is an argument?

> "An argument is the actual value passed to a function when calling it."

```javascript
add(10, 20);
```

`10` and `20` are arguments.

---

### Q4. What is the difference between parameter and argument?

| Parameter | Argument |
|---|---|
| Function declaration లో ఉంటుంది | Function call లో ఉంటుంది |
| Placeholder | Actual value |
| `a, b` | `10, 20` |

🧠 Remember:

> **Parameter = Placeholder**  
> **Argument = Actual value**

---

### Q5. What is `return`?

**Answer:**

> "`return` sends a value from the function back to the caller."

---

### Q6. Why do we use functions in automation?

**Answer:**

> "We use functions to create reusable code, reduce code duplication, improve maintainability, and perform specific actions."

---

### Q7. Can a function accept multiple parameters?

**Answer:**

> "Yes. A JavaScript function can accept multiple parameters."

Example:

```javascript
function login(username, password) {
    console.log(username);
    console.log(password);
}
```

### Simple Example

```javascript
function greet() {
    console.log("Hello Satya");
}

greet();
```

Output:

```text
Hello Satya
```

### Important

```text
function greet()   → Function declaration
greet()            → Function call
```


# 2. Function Syntax

```javascript
function functionName() {
    // code

```

Example:

```javascript
function login() {
    console.log("Login successful");
}
```

Function create చేశాం.

కానీ అది automatically execute అవ్వదు.

Execute చేయడానికి:

```javascript
login();
```

# 3. Parameters

Function కి input ఇవ్వడానికి **parameters** ఉపయోగిస్తాం.

```javascript
function greet(name) {
    console.log("Hello " + name);
}

greet("Satya");
```

Output:

```text
Hello Satya
```

ఇక్కడ:

```text
name       → Parameter
"Satya"    → Argument
```

### Telugu

Function definition లో మనం పెట్టే variable = **Parameter**

Function call చేసేటప్పుడు ఇచ్చే actual value = **Argument**

---

# 4. Multiple Parameters

ఒక function కి multiple inputs ఇవ్వవచ్చు.

```javascript
function add(a, b) {
    console.log(a + b);
}

add(10, 20);
```

Output:

```text
30
```

ఇక్కడ:

```text
a, b       → Parameters
10, 20     → Arguments
```

# 5. Return Value ⭐

Function ఒక result ని తిరిగి ఇవ్వాలంటే `return` ఉపయోగిస్తాం.

```javascript
function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);
```

Output:

```text
30
```

### Telugu

`return` అంటే:

> Function calculate చేసిన result ని బయటకు పంపించు.

---

## 6. `console.log()` vs `return`

ఇది interview లో అడగవచ్చు.

### `console.log()`

Screen/console లో value చూపిస్తుంది.

```javascript
function add(a, b) {
    console.log(a + b);
}

add(10, 20);
```

### `return`

Value ని function నుండి బయటకు పంపిస్తుంది.

```javascript
function add(a, b) {
    return a + b;
}

let result = add(10, 20);
```

### Easy Memory 🧠

**console.log → Show**

**return → Send back**

# 7. Function with Condition

```javascript
function checkAge(age) {

    if (age >= 18) {
        return "Adult";
    } else {
        return "Minor";
    }

console.log(checkAge(25));
```

Output:

```text
Adult
```

# 8. Real-Time Playwright Example ⭐

Suppose login action repeatedly perform చేయాలి.

Instead of writing:

```javascript
await page.getByLabel("Username").fill("satya");
await page.getByLabel("Password").fill("12345");
await page.getByRole("button", { name: "Login" }).click();
```

Every test లో same code రాయకుండా reusable function చేయవచ్చు:

```javascript
async function login(page, username, password) {

    await page.getByLabel("Username").fill(username);
    await page.getByLabel("Password").fill(password);
    await page.getByRole("button", { name: "Login" }).click();
}
```

Then test లో:

```javascript
await login(page, "satya", "12345");
```

### Telugu

ఒకసారి function రాశాం.

తర్వాత అవసరమైన ప్రతి test లో:

```javascript
login(page, username, password);
```

అని call చేయవచ్చు.

**Benefit:** Code duplication తగ్గుతుంది మరియు reusable code అవుతుంది.

# 9. Function with `async`

Playwright లో asynchronous actions ఉంటాయి కాబట్టి functions తరచుగా `async` గా ఉంటాయి.

```javascript
async function login(page) {
    await page.getByRole("button", { name: "Login" }).click();
}
```

ఇక్కడ:

```text
async → asynchronous function
await → operation complete అయ్యే వరకు wait
```

ఇది మనం **Async JavaScript** topic లో detailed గా నేర్చుకుంటాం.

# 10. Default Parameters

Parameter కి default value ఇవ్వవచ్చు.

```javascript
function greet(name = "User") {
    console.log("Hello " + name);
}

greet();
```

Output:

```text
Hello User
```

Value ఇస్తే:

```javascript
greet("Satya");
```

Output:

```text
Hello Satya
```

# 11. Function Without Parameters

```javascript
function openWebsite() {

}

openWebsite();
```

No input required.

# 12. Function With Parameters
