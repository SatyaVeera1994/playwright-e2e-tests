

## String Methods – Image Based Cheat Sheet

| Method          | Meaning                 | Example                       |
| --------------- | ----------------------- | ----------------------------- |
| `split()`       | String → Array          | `"Hi All".split(" ")`         |
| `replace()`     | Replace text            | `"Hello".replace("H","Y")`    |
| `trim()`        | Remove both-side spaces | `" Hi ".trim()`               |
| `toUpperCase()` | Convert uppercase       | `"hello".toUpperCase()`       |
| `charAt()`      | Get character by index  | `"Hello".charAt(1)`           |
| `toLowerCase()` | Convert lowercase       | `"HELLO".toLowerCase()`       |
| `substring()`   | Extract part of string  | `"JavaScript".substring(0,4)` |

## Easy Examples to Remember

```
let str = "  Hello JavaScript  ";

console.log(str.split(" "));
// ["", "", "Hello", "JavaScript", "", ""]

console.log(str.trim());
// "Hello JavaScript"

console.log(str.charAt(0));
// " "

console.log(str.toUpperCase());
// "  HELLO JAVASCRIPT  "

console.log(str.toLowerCase());
// "  hello javascript  "

console.log(str.replace("Hello", "Hi"));
// "  Hi JavaScript  "

console.log(str.substring(2, 7));
// "Hello"
```

## 2. One-Line Syntax Cheat Sheet

```
let str = "Hello JavaScript";

// 1. Count characters
str.length;

// 2. Get character
str.charAt(0);

// 3. Character code
str.charCodeAt(0);

// 4. Get character using at
str.at(-1);

// 5. Access using index
str[0];

// 6. Extract string
str.slice(0, 5);

// 7. Extract string
str.substring(0, 5);

// 8. Uppercase
str.toUpperCase();

// 9. Lowercase
str.toLowerCase();

// 10. Combine strings
str.concat(" World");

// 11. Remove spaces both sides
str.trim();

// 12. Remove starting spaces
str.trimStart();

// 13. Remove ending spaces
str.trimEnd();

// 14. Add characters at start
"5".padStart(3, "0");

// 15. Add characters at end
"5".padEnd(3, "0");

// 16. Repeat string
"Hi ".repeat(3);

// 17. Replace first match
"Hello World".replace("World", "Satya");

// 18. Replace all matches
"Hi Hi Hi".replaceAll("Hi", "Hello");

// 19. String to Array
"Apple Banana Mango".split(" ");
```

## 3. Important String Methods with Examples

### 1. `length`

String లో ఎన్ని characters ఉన్నాయో తెలుసుకోవడానికి.

```
let name = "Satya";
console.log(name.length); // 5
```

### 2. `charAt()` vs `at()`

```
let str = "Hello";

console.log(str.charAt(1)); // e
console.log(str.at(-1));    // o
```

`at()` negative indexing support చేస్తుంది. `charAt()` చేయదు.

### 3. `slice()` vs `substring()`

```
let str = "JavaScript";

console.log(str.slice(0, 4));      // Java
console.log(str.substring(0, 4));  // Java
```

| slice()                                  | substring()                        |
| ---------------------------------------- | ---------------------------------- |
| Negative indexes support                 | Negative values become 0           |
| End index excluded                       | End index excluded                 |
| Can return from end using negative index | Does not support negative indexing |

### 4. `toUpperCase()` / `toLowerCase()`

```
let str = "JavaScript";

console.log(str.toUpperCase()); // JAVASCRIPT
console.log(str.toLowerCase()); // javascript
```

### 5. `trim()` methods

```
let str = "  Hello  ";

console.log(str.trim());      // "Hello"
console.log(str.trimStart()); // "Hello  "
console.log(str.trimEnd());   // "  Hello"
```

### 6. `replace()` vs `replaceAll()`

```
let str = "Hi Hi Hi";

console.log(str.replace("Hi", "Hello"));
// Hello Hi Hi

console.log(str.replaceAll("Hi", "Hello"));
// Hello Hello Hello
```

### 7. `split()`

String ను Array గా convert చేస్తుంది.

```
let sentence = "Keep Moving Forward";

let words = sentence.split(" ");

console.log(words);
// ["Keep", "Moving", "Forward"]
```

## 4. Most Important Interview Differences

String slice vs Array slice

రెండూ specified range ను extract చేసి కొత్త value return చేస్తాయి. Original value మారదు.

replace vs replaceAll

- `replace()` → First matching occurrence మాత్రమే.
- `replaceAll()` → All matching occurrences.

charAt vs at

- `charAt(0)` → First character.
- `at(-1)` → Last character.

split vs join

- `split()` → String to Array.
- `join()` → Array to String.

## 6. SDET / Playwright Real-Time Examples

Example 1: Verify text without case sensitivity

```
const actualText = "LOGIN SUCCESS";
const expectedText = "login success";

console.log(
  actualText.toLowerCase() === expectedText.toLowerCase()
); // true
```

Example 2: Remove extra spaces

```
const username = "  Satya  ";

console.log(username.trim()); // Satya
```

Example 3: Split API response text

```
const response = "Admin,Tester,Developer";

const roles = response.split(",");

console.log(roles);
// ["Admin", "Tester", "Developer"]
```
