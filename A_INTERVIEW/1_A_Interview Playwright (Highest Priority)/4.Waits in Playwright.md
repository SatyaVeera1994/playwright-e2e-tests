## Different Types of Waits in Playwright

Interview Answer (Simple English):

“In Playwright, we use different types of waits to ensure that elements are ready before performing actions. The main types are Auto-waiting, Wait for Element State, Wait for Navigation, and Assertion-based Waiting.”

## Short Interview Answer

“I mainly use Playwright's built-in auto-waiting and assertion-based waiting. I use `waitFor()` or `waitForURL()` when required. I avoid fixed waits because they increase execution time and can make tests unreliable.”

### 1. Auto-waiting (Most commonly used)

```
await page.getByRole('button', { name: 'Login' }).click();
```

- Playwright automatically waits until the button is ready to be clicked.
- We don't need to add a separate wait in most cases.

### 2. Wait for Element State

```
await page.locator('button').waitFor({ state: 'visible' });
```

- Waits until the element becomes visible.
- We can also use `hidden`, `attached`, and `detached` states.

### 3. Wait for Navigation

```
await page.getByRole('link', { name: 'Dashboard' }).click();
await page.waitForURL('**/dashboard');
```

- Used when we need to wait for a URL change.
- `waitForURL()` is useful for verifying navigation.

### 4. Assertion-based Waiting

```
await expect(page.getByText('Login successful')).toBeVisible();
```

- Playwright automatically retries the assertion until the element becomes visible or the timeout is reached.
- Used to verify the expected result.

### 5. Fixed Wait (Not Recommended)

```
await page.waitForTimeout(3000);
```

- Waits for 3 seconds.
- We generally avoid fixed waits because they make tests slower and less reliable.

## Short Interview Answer

“I mainly use Playwright's built-in auto-waiting and assertion-based waiting. I use `waitFor()` or `waitForURL()` when required. I avoid fixed waits because they increase execution time and can make tests unreliable.”
