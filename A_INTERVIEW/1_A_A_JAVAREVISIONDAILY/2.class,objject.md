## What is an Object in JavaScript?

An Object in JavaScript is a collection of key-value pairs. It is used to store multiple related data in a single variable.

Simple ga cheppalante, object ante one entity ki related information ni store cheyadam.

### 1. Real-time example

Think about an employee. An employee has:

- Name
- Age
- Salary
- Department

We can store all this information in one object.

### 2. JavaScript code

```
const employee = {
    name: "Satya",
    age: 28,
    salary: 50000,
    department: "QA"
};

console.log(employee);
```

Output:

```
{
    name: "Satya",
    age: 28,
    salary: 50000,
    department: "QA"
}
```

### 3. How to access object properties?

There are two ways.

Method 1: Dot notation

```
console.log(employee.name);
console.log(employee.age);
```

Output:

```
Satya
28
```

Method 2: Bracket notation

```
console.log(employee["name"]);
console.log(employee["salary"]);
```

Output:

```
Satya
50000
```

### 4. How to add, update and delete properties?

```
const employee = {
    name: "Satya",
    age: 28
};

// Add property
employee.city = "Bangalore";

// Update property
employee.age = 29;

// Delete property
delete employee.name;

console.log(employee);
```

Output:

```
{
    age: 29,
    city: "Bangalore"
}
```

### 5. Object with a function (Method)

An object can also contain functions.

```
const employee = {
    name: "Satya",

    greet: function() {
        console.log("Hello, welcome!");
    }
};

employee.greet();
```

Output:

```
Hello, welcome!
```

### 6. Object in Playwright – Real-time example

In Playwright, we commonly use objects to store test data.

```
const loginData = {
    username: "admin",
    password: "admin123",
    url: "https://example.com"
};

await page.goto(loginData.url);

await page.locator("#username").fill(loginData.username);

await page.locator("#password").fill(loginData.password);
```

Here, `loginData` is an object containing login-related test data.

### 7. Interview-ready answer

Q: What is an object in JavaScript?

"An object in JavaScript is a collection of key-value pairs. It is used to store related data and functions in a single variable. We can access object properties using dot notation or bracket notation."

## What are Classes in JavaScript?

A Class in JavaScript is a blueprint or template used to create objects.

Simple ga cheppalante:

- Class = Blueprint (Design)
- Object = Real instance created using that blueprint.

Company creates one car design (blueprint). Using that design, they manufacture multiple cars.

- Class = Car design
- Objects = BMW, Audi, Tata cars

### 2. How to create a class in JavaScript?

```
class Car {

    constructor(brand, color) {
        this.brand = brand;
        this.color = color;
    }

    start() {
        console.log("Car started");
    }
}
```

Explanation in Telugu:

- `class Car` → Car ane class create chestunnam.
- `constructor()` → Object create chesinappudu automatically execute avutundi.
- `this.brand` → Current object yokka brand.
- `this.color` → Current object yokka color.
- `start()` → Class lo define chesina method.

### 3. How to create objects using a class?

```
class Car {

    constructor(brand, color) {
        this.brand = brand;
        this.color = color;
    }

    start() {
        console.log("Car started");
    }
}

const car1 = new Car("BMW", "Black");
const car2 = new Car("Audi", "White");

console.log(car1.brand);
console.log(car2.brand);

car1.start();
```

Output:

```
BMW
Audi
Car started
```

Here:

- `Car` → Class
- `car1`, `car2` → Objects
- `new` → Creates a new object.
- `constructor` → Initializes object properties.

### 4. Class vs Object

| Class                          | Object                 |
| ------------------------------ | ---------------------- |
| Blueprint                      | Real instance          |
| Defines properties and methods | Contains actual values |
| Created using `class`          | Created using `new`    |
| Example: Car                   | Example: BMW           |

### 5. Real-time Playwright example

In Playwright, we use classes in the Page Object Model (POM).

```
import { Page, Locator } from '@playwright/test';

class LoginPage {

    page: Page;
    username: Locator;
    password: Locator;
    loginButton: Locator;

    constructor(page: Page) {
        this.page = page;
        this.username = page.locator('#username');
        this.password = page.locator('#password');
        this.loginButton = page.locator('#login');
    }

    async login(user: string, pass: string) {
        await this.username.fill(user);
        await this.password.fill(pass);
        await this.loginButton.click();
    }
}
```

Using this class in a test:

```
test('Login Test', async ({ page }) => {

    const loginPage = new LoginPage(page);

    await page.goto('https://example.com');

    await loginPage.login('admin', 'admin123');

});
```

Telugu explanation:

Manam `LoginPage` ane class create chesam.

- Constructor lo page and locators initialize chestham.
- Login method lo username, password fill chestham.
- Test lo `new LoginPage(page)` use chesi object create chestham.
- `loginPage.login()` call chesi login operation perform chestham.
