## Different Timeout Types in Playwright

Interview Answer (Simple English):

“In Playwright, there are five main timeout types: Test Timeout, Action Timeout, Navigation Timeout, Assertion Timeout, and Global Timeout. Each timeout controls how long Playwright waits for a specific operation or test execution.”

### 1. Test Timeout

- Controls the maximum time allowed for one test to complete.
- Default: 30 seconds.

```
export default {
  timeout: 60000,
};
```

### 2. Action Timeout

- Controls how long an action, such as click or fill, can wait to become actionable.
- Configured globally or for an individual action.

```
await page.getByRole('button', { name: 'Login' })
  .click({ timeout: 5000 });
```

Global configuration:

```
use: {
  actionTimeout: 10000,
}
```

### 3. Navigation Timeout

- Controls how long navigation-related operations can wait.
- Can be configured globally or for a specific operation.

```
await page.goto('/dashboard', { timeout: 15000 });
```

Global configuration:

```
use: {
  navigationTimeout: 30000,
}
```

### 4. Assertion Timeout

- Controls how long an assertion retries before failing.
- Default: 5 seconds.

```
expect: {
  timeout: 10000,
}
```

Example:

```
await expect(page.getByText('Welcome'))
  .toBeVisible();
```

### 5. Global Timeout

- Controls the maximum duration of the entire test run.
- By default, it is unlimited.

```
export default {
  globalTimeout: 3600000,
};
```

This allows the entire test run to take up to one hour.

## Complete Configuration Example

```
import { defineConfig } from '@playwright/test';

export default defineConfig({
  timeout: 30000,

  expect: {
    timeout: 5000,
  },

  globalTimeout: 3600000,

  use: {
    actionTimeout: 10000,
    navigationTimeout: 30000,
  },
});
```

## Quick Interview Revision

| Timeout            | Purpose                               |
| ------------------ | ------------------------------------- |
| Test Timeout       | Maximum time for one test             |
| Action Timeout     | Time allowed for an action            |
| Navigation Timeout | Time allowed for navigation           |
| Assertion Timeout  | Time allowed for an assertion to pass |
| Global Timeout     | Maximum time for the entire test run  |

Important: Action and navigation timeouts are generally unlimited by default, while test timeout is 30 seconds and assertion timeout is 5 seconds. You can configure them according to your project requirements.
