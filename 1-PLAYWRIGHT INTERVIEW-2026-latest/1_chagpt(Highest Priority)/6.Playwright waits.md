Since you're preparing for a **Playwright interview**, focus only on **Playwright waits**.

# ⭐ Playwright Waits

Playwright has **two types of waits**:

1. **Auto Waiting (Built-in)** ✅
2. **Explicit Waits (Manual)** ✅

> **Playwright does NOT have Implicit Wait.**

---

# 1. Auto Waiting

## ✅ Interview Answer (English)

> Auto Waiting is a built-in Playwright feature that automatically waits until an element is ready before performing actions like `click()`, `fill()`, or `check()`.

## ✅ Interview Answer (Telugu)

> **Auto Waiting అనేది Playwright లో built-in feature. Element ready అయ్యే వరకు automatically wait చేసి తర్వాత action చేస్తుంది.**

### Example

```typescript
await page.getByRole("button", { name: "Login" }).click();
```

👉 No explicit wait needed.

---

# 2. Explicit Wait

## ✅ Interview Answer (English)

> Explicit Wait is used when we need to wait for a specific event or condition that Auto Waiting cannot handle.

## ✅ Interview Answer (Telugu)

> **Auto Waiting handle చేయలేని ప్రత్యేక పరిస్థితుల్లో Explicit Wait ఉపయోగిస్తాము.**

---

# Common Explicit Waits in Playwright

### Wait for URL

```typescript
await page.waitForURL("**/dashboard");
```

### Wait for API Response

```typescript
await page.waitForResponse("**/login");
```

### Wait for Load State

```typescript
await page.waitForLoadState("networkidle");
```

### Wait for Download

```typescript
const downloadPromise = page.waitForEvent("download");
```

### Wait for Selector

```typescript
await page.waitForSelector("#success-message");
```

---

# Difference Between Auto Waiting and Explicit Wait

| Auto Waiting                       | Explicit Wait                                 |
| ---------------------------------- | --------------------------------------------- |
| Built into Playwright              | Manually written by the tester                |
| Waits automatically before actions | Waits for a specific event or condition       |
| Used for click(), fill(), check()  | Used for URL, API, Download, Load State, etc. |
| Reduces flaky tests                | Used only when required                       |

# ⭐ Interview Question

### **Does Playwright support Implicit Wait?**

### ✅ English

> **No. Playwright does not support Implicit Wait. It uses Auto Waiting instead.**

### ✅ Telugu

> **లేదు. Playwright లో Implicit Wait ఉండదు. దాని బదులుగా Auto Waiting ఉంటుంది.**

# ⭐ Interview Question

### **When do you use Explicit Wait in Playwright?**

### ✅ English

> **I use Explicit Wait for URL changes, API responses, file downloads, page load states, and other specific conditions that Auto Waiting does not handle.**

### ✅ Telugu

> **URL change, API response, File Download, Page Load State మరియు Auto Waiting handle చేయలేని ప్రత్యేక పరిస్థితుల్లో Explicit Wait ఉపయోగిస్తాను.**

---

# ⭐ Easy Memory Trick

✅ **Auto Waiting** → **Element Actions** (`click`, `fill`, `check`)

✅ **Explicit Wait** → **URL, API, Download, Load State**

❌ **Implicit Wait** → **Not available in Playwright**

### 🎯 One-line Interview Answer

> **Playwright has built-in Auto Waiting for element actions, and Explicit Waits are used only for specific events like URL changes, API responses, downloads, or page load states. Playwright does not support Implicit Wait.**
