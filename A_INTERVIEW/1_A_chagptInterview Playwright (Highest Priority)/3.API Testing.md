# ⭐⭐⭐⭐⭐ API Testing - Last Minute Interview Revision (English + Telugu)

---

# ⭐ 1. What is GET?

### ✅ English

> **GET** is used to retrieve data from the server.

### ✅ Telugu

> **GET method server నుండి data తీసుకోవడానికి ఉపయోగిస్తాము.**

**Example**

```http
GET /users
```

---

# ⭐ 2. What is POST?

### ✅ English

> **POST** is used to create new data on the server.

### ✅ Telugu

> **POST method server లో కొత్త data create చేయడానికి ఉపయోగిస్తాము.**

**Example**

```http
POST /users
```

---

# ⭐ 3. Difference between GET and POST?

### ✅ English

- **GET** → Retrieve data
- **POST** → Create data

### ✅ Telugu

- **GET** → Data తీసుకోవడానికి
- **POST** → కొత్త Data create చేయడానికి

---

### ✅ Telugu

# ⭐ 8. What are Status Codes?

### ✅ English

> Status codes tell whether the API request was successful or failed.

### ✅ Telugu

> **Status Codes API request success లేదా failure ని తెలియజేస్తాయి.**

# ⭐ 9. Common Status Codes

| Code                          | English                 | Telugu                       |
| ----------------------------- | ----------------------- | ---------------------------- |
| **200 OK**                    | Request successful      | **Request Success**          |
| **201 Created**               | Resource created        | **కొత్త Data Create అయింది** |
| **400 Bad Request**           | Invalid request         | **Wrong Request**            |
| **401 Unauthorized**          | Authentication required | **Login/Auth లేదు**          |
| **403 Forbidden**             | Access denied           | **Permission లేదు**          |
| **404 Not Found**             | Resource not found      | **Data దొరకలేదు**            |
| **500 Internal Server Error** | Server error            | **Server Error**             |

# ⭐ 12. What is a Bearer Token?

### ✅ English

> A Bearer Token is an access token used to authenticate API requests.

### ✅ Telugu

> **Bearer Token API requests authenticate చేయడానికి ఉపయోగించే access token.**


### ✅ Telugu

# ⭐ 14. What is Response Validation?

### ✅ English

> Response Validation verifies the status code, response body, headers, and response time.

### ✅ Telugu

> **Response Validation లో Status Code, Response Body, Headers మరియు Response Time ని verify చేస్తాము.**

---

# ⭐ 15. What is API Chaining?

### ✅ English

> API Chaining means using the response from one API request in another API request.

### ✅ Telugu

> **ఒక API response ని మరో API request లో ఉపయోగించడాన్ని API Chaining అంటారు.**

**Example**

```text
Login API

↓

Get Token

↓

Use Token

↓

Get User API
```

---

# ⭐ 16. How do you perform API Testing using Playwright?

### ✅ English

> I use **APIRequestContext** to send GET, POST, PUT, PATCH, and DELETE requests, then validate the status code and response body.

### ✅ Telugu

> **Playwright లో APIRequestContext ఉపయోగించి GET, POST, PUT, PATCH, DELETE requests పంపి, Status Code మరియు Response ని verify చేస్తాను.**

**Example**

```typescript
const response = await request.get("/users");

expect(response.status()).toBe(200);
```
