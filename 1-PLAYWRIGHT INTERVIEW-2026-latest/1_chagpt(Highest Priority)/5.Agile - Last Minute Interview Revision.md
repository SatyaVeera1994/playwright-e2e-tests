# ⭐⭐⭐⭐⭐ Agile - Last Minute Interview Revision (English + Telugu)

---

# ⭐ 1. What is Agile?

### ✅ English

> Agile is a software development methodology where work is completed in small iterations called sprints.

### ✅ Telugu

> **Agile అనేది software ని చిన్న చిన్న iterations (Sprints) లో develop చేసే methodology.**

---

# ⭐ 2. What is Scrum?

### ✅ English

> Scrum is an Agile framework used to manage and deliver projects in short sprints.

### ✅ Telugu

> **Scrum అనేది Agile framework. ఇందులో project ని చిన్న చిన్న Sprints లో complete చేస్తారు.**

---

# ⭐ 3. What is a Sprint?

### ✅ English

> A Sprint is a fixed time period (usually 2 weeks) in which the team completes planned work.

### ✅ Telugu

> **Sprint అంటే 2 వారాల వంటి fixed time period. ఈ సమయంలో team planned work complete చేస్తుంది.**

---

# ⭐ 4. What is a Daily Stand-up?

### ✅ English

> Daily Stand-up is a 15-minute meeting where team members discuss yesterday's work, today's plan, and any blockers.

### ✅ Telugu

> **Daily Stand-up అనేది 15 నిమిషాల meeting. ఇందులో నిన్న చేసిన పని, ఈరోజు చేసే పని, ఎదురైన సమస్యలు గురించి మాట్లాడతాము.**

---

# ⭐ 5. What is Sprint Planning?

### ✅ English

> Sprint Planning is a meeting where the team decides which user stories will be completed in the upcoming sprint.

### ✅ Telugu

> **Sprint Planning లో వచ్చే Sprint లో ఏ User Stories పూర్తి చేయాలో నిర్ణయిస్తారు.**

---

# ⭐ 6. What is Sprint Review?

### ✅ English

> Sprint Review is a meeting where the completed work is demonstrated to stakeholders for feedback.

### ✅ Telugu

> **Sprint Review లో Sprint లో పూర్తయిన work ని stakeholders కి చూపించి feedback తీసుకుంటారు.**

---

# ⭐ 7. What is a Retrospective?

### ✅ English

> Retrospective is a meeting where the team discusses what went well, what can be improved, and action items for the next sprint.

### ✅ Telugu

> **Retrospective లో ఏమి బాగా జరిగింది, ఏమి improve చేయాలి అనే విషయాలను చర్చిస్తారు.**

---

# ⭐ 8. What is a User Story?

### ✅ English

> A User Story is a short description of a feature from the user's perspective.

### ✅ Telugu

> **User Story అంటే User దృష్టిలో ఒక feature యొక్క చిన్న description.**

**Example:**

> As a user, I want to log in so that I can access my account.

---

# ⭐ 9. What is an Epic?

### ✅ English

> An Epic is a large feature that is divided into multiple user stories.

### ✅ Telugu

> **Epic అంటే పెద్ద feature. దాన్ని చిన్న చిన్న User Stories గా విభజిస్తారు.**

---

# ⭐ 10. What are Acceptance Criteria?

### ✅ English

> Acceptance Criteria are the conditions that must be met for a user story to be considered complete.

### ✅ Telugu

> **Acceptance Criteria అంటే User Story complete అయిందని చెప్పడానికి తప్పనిసరిగా meet కావాల్సిన conditions.**

---

# ⭐⭐⭐⭐⭐ Real-Time Project Question

## Q. What Agile ceremonies did you attend?

### ✅ English

> In my project, I attended Daily Stand-up, Sprint Planning, Sprint Review, and Sprint Retrospective meetings. We also discussed user stories and acceptance criteria before starting testing.

### ✅ Telugu

> **మా Project లో Daily Stand-up, Sprint Planning, Sprint Review, Sprint Retrospective meetings కి హాజరయ్యాను. Testing ప్రారంభించే ముందు User Stories మరియు Acceptance Criteria ని discuss చేసేవాళ్లం.**

# ⭐⭐⭐⭐⭐ Most Asked Interview Questions

### Q1. What is Agile?

**English:**

> Agile is a software development methodology that delivers work in small sprints.

**Telugu:**

> **Agile అనేది చిన్న చిన్న Sprints లో software develop చేసే methodology.**

---

### Q2. What is Scrum?

**English:**

> Scrum is an Agile framework used to manage projects.

**Telugu:**

> **Scrum అనేది Agile Framework.**

---

### Q3. What happens in a Daily Stand-up?

**English:**

> We discuss yesterday's work, today's plan, and blockers.

**Telugu:**

> **నిన్న చేసిన పని, ఈరోజు చేసే పని, వచ్చిన సమస్యలు గురించి మాట్లాడుతాము.**

---

### Q4. What is the difference between Epic and User Story?

**English:**

> An Epic is a large feature, while a User Story is a small requirement within that feature.

**Telugu:**

> **Epic పెద్ద Feature, User Story ఆ Feature లోని చిన్న Requirement.**

---

### Q5. What are Acceptance Criteria?

**English:**

> Acceptance Criteria define when a user story is considered complete.

**Telugu:**

> **User Story complete అయిందని చెప్పడానికి ఉండే conditions ని Acceptance Criteria అంటారు.**
