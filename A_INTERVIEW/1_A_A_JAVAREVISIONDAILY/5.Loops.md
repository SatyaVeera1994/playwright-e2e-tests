# Module 1 – Topic 5: Loops 🔄

**Simple Telugu + English | JavaScript + Playwright Interview Preparation**

Satya, **Loop** అంటే ఒకే code ని **multiple times repeat చేయడం**.

### Easy Telugu

Suppose మన దగ్గర:

```text
Test Case 1
Test Case 2
Test Case 3
Test Case 4
Test Case 5
```

అన్నింటికీ same action చేయాలి.

ప్రతి test case కోసం separate code రాయడం బదులు **loop** ఉపయోగిస్తాం.

---

# 1. `for` Loop ⭐

`for` loop చాలా common.

### Syntax

```javascript
for (initialization; condition; increment) {
    // code
}
```

### Simple Example

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

### Output

```text
1
2
3
4
5
```

### How to read it?

```text
let i = 1       → Start
i <= 5          → Condition
i++             → Increase by 1
```

### Telugu

మొదట `i = 1`

`i <= 5` ఉన్నంత వరకు loop run అవుతుంది.

ప్రతి iteration తర్వాత `i++` వల్ల 1 పెరుగుతుంది.

---

# 2. `i++` అంటే ఏమిటి?

```javascript
i++;
```

means:

```javascript
i = i + 1;
```

Example:

```text
i = 1
i++ → 2
i++ → 3
i++ → 4
```

---

# 3. Reverse `for` Loop

5 నుంచి 1 వరకు print చేయాలి.

```javascript
for (let i = 5; i >= 1; i--) {
    console.log(i);
}
```

Output:

```text
5
4
3
2
1
```

`i--` means:

```javascript
i = i - 1;
```

---

# 4. Loop Through an Array ⭐

ఇది automation లో చాలా useful.

```javascript
let browsers = ["Chrome", "Firefox", "WebKit"];

for (let i = 0; i < browsers.length; i++) {
    console.log(browsers[i]);
}
```

Output:

```text
Chrome
Firefox
WebKit
```

### Telugu

Array లో 3 browsers ఉన్నాయి.

Loop ప్రతి browser ని ఒక్కొక్కటిగా తీసుకుంటుంది.

```text
browsers[0] → Chrome
browsers[1] → Firefox
browsers[2] → WebKit
```

---

# 5. `while` Loop

Condition true ఉన్నంత వరకు loop execute అవుతుంది.

### Syntax

```javascript
while (condition) {
    // code
}
```

### Example

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

Output:

```text
1
2
3
4
5
```

### Telugu

`while` లో ముందుగా condition check చేస్తుంది.

Condition `true` అయితే code execute అవుతుంది.

---

# 6. `for` vs `while`

| `for` | `while` |
|---|---|
| Number of iterations తెలిసినప్పుడు useful | Condition-based looping |
| Initialization, condition, increment ఒకే line లో | Separate lines |
| Arrays/data iteration కి common | Unknown number of iterations కి useful |

### Easy Memory 🧠

**for → ఎంతసార్లు run చేయాలో roughly తెలుసు**

**while → condition true ఉన్నంత వరకు**

---

# 7. `break` ⭐

Loop ని **immediately stop** చేయడానికి `break` ఉపయోగిస్తాం.

```javascript
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        break;
    }

    console.log(i);
}
```

Output:

```text
1
2
```

### Why 3 print కాలేదు?

`i === 3` అయినప్పుడు:

```javascript
break;
```

execute అయింది.

అందుకే loop అక్కడే stop అయింది.

### Easy memory

**break = Stop the loop**

---

# 8. `continue` ⭐

Current iteration ని **skip** చేసి next iteration కి వెళ్తుంది.

```javascript
for (let i = 1; i <= 5; i++) {

    if (i === 3) {
        continue;
    }

    console.log(i);
}
```

Output:

```text
1
2
4
5
```

### Why 3 లేదు?

`i === 3` అయినప్పుడు `continue` execute అయింది.

అందుకే 3 skip అయింది.

### Easy memory

**continue = Skip current iteration**

---

# 9. `break` vs `continue` ⭐ Interview Question

| `break` | `continue` |
|---|---|
| Entire loop stops | Current iteration skips |
| Loop నుంచి బయటకు వస్తుంది | Next iteration కి వెళ్తుంది |
| **STOP** | **SKIP** |

🧠 Remember:

> **break = Stop**  
> **continue = Skip**

# 10. Real-Time Playwright Example

Suppose మనకు multiple usernames ఉన్నాయి.

```javascript
let users = ["user1", "user2", "user3"];

for (let user of users) {
    console.log("Testing user:", user);
}
```

Output:

```text
Testing user: user1
Testing user: user2
Testing user: user3
```

Real automation లో test data తో similar looping concept ఉపయోగించవచ్చు.

# 11. `for...of` Loop

Array values directly తీసుకోవడానికి `for...of` చాలా easy.

```javascript
let browsers = ["Chrome", "Firefox", "WebKit"];

for (let browser of browsers) {
    console.log(browser);
}
```

Output:

```text
Chrome
Firefox
WebKit
```

### Difference

Traditional `for`:

```javascript
for (let i = 0; i < browsers.length; i++) {
    console.log(browsers[i]);
}
```

`for...of`:

```javascript
for (let browser of browsers) {
    console.log(browser);
}
```

**Beginner-friendly:** `for...of` చదవడానికి easy.

# 🎯 Interview Questions

### Q1. What is a loop?

**English:**

> "A loop is used to execute a block of code repeatedly based on a condition."

**Telugu:**

ఒక code block ని repeated గా execute చేయడానికి loop ఉపయోగిస్తాం.

---

### Q2. What are the common loops in JavaScript?

**Answer:**

> "Common loops are `for`, `while`, `do...while`, `for...of`, and `for...in`."

For your current preparation, focus especially on:

**`for`, `while`, `for...of`**

---

### Q3. What is the difference between `break` and `continue`?

**Interview Answer:**

> "`break` terminates the loop completely, while `continue` skips the current iteration and moves to the next iteration."

---

### Q4. What is `i++`?

> "`i++` increments the value of `i` by 1."

Example:

```javascript
let i = 5;
i++;

console.log(i);
```

Output:

```text
6
```

---

### Q5. How do you loop through an array?

**Answer:**

```javascript
let names = ["Satya", "Ravi", "John"];

for (let name of names) {
    console.log(name);
}
```

> "I can use a `for...of` loop to iterate through the values of an array."
