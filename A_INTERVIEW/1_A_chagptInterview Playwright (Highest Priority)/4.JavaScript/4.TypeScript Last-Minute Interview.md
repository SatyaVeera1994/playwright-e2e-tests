# ⭐ 1. var vs let vs const

### ✅ English

- **var** → Can be redeclared and updated.
- **let** → Cannot be redeclared but can be updated.
- **const** → Cannot be redeclared or updated.

### ✅ Telugu

- **var** → మళ్లీ declare చేయవచ్చు, value మార్చవచ్చు.
- **let** → మళ్లీ declare చేయలేము, value మార్చవచ్చు.
- **const** → మళ్లీ declare చేయలేము, value కూడా మార్చలేము.

**Example**

```javascript
var a = 10;
let b = 20;
const c = 30;
```

# ⭐ 2. == vs ===

### ✅ English

- **==** checks value only.
- **===** checks value and data type.

### ✅ Telugu

- **==** value మాత్రమే compare చేస్తుంది.
- **===** value మరియు data type రెండూ compare చేస్తుంది.

**Example**

```javascript
5 == "5"; // true
5 === "5"; // false
```

# ⭐ 9. Objects & Arrays

### ✅ English

- **Object** stores data as key-value pairs.
- **Array** stores multiple values in a list.

### ✅ Telugu

- **Object** → Key-Value pairs లో data store చేస్తుంది.
- **Array** → Multiple values ని list రూపంలో store చేస్తుంది.

**Example**

```javascript
const user = { name: "John", age: 25 };

const fruits = ["Apple", "Mango"];
```

# ⭐ 10. Destructuring

### ✅ English

Destructuring extracts values from objects or arrays.

### ✅ Telugu

**Object లేదా Array నుండి values ని తీసుకోవడానికి Destructuring ఉపయోగిస్తాము.**

**Example**

```javascript
const user = { name: "John" };

const { name } = user;
```

# ⭐ 11. Spread Operator (...)

### ✅ English

The spread operator copies or merges arrays and objects.

### ✅ Telugu

**Spread Operator (...) arrays లేదా objects ని copy లేదా merge చేయడానికి ఉపయోగిస్తాము.**

**Example**

```javascript
const arr1 = [1, 2];

const arr2 = [...arr1, 3];
```

# ⭐ 12. Template Literals

### ✅ English

Template literals use backticks (` `) to create strings with variables.

### ✅ Telugu

**Backticks (` `) ఉపయోగించి variables తో string create చేయడానికి Template Literals ఉపయోగిస్తాము.**

**Example**


# ⭐ 13. Closures (Basic)

### ✅ English

A closure is a function that remembers variables from its outer function even after the outer function has finished.

### ✅ Telugu

**Closure అంటే outer function పూర్తయినా, దాని variables ని inner function గుర్తుంచుకోవడం.**

# ⭐ 14. Modules (import/export)

### ✅ English

Modules help organize code by exporting and importing functions or variables between files.

### ✅ Telugu

**Modules ద్వారా ఒక file లోని functions లేదా variables ని మరో file లో ఉపయోగించవచ్చు.**

**Example**

```javascript
// export
export function login() {}
```

```javascript
// import
import { login } from "./login";
```
