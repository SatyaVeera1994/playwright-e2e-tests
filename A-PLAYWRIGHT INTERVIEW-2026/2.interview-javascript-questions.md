Here is a simple JavaScript program to reverse a string.

### Example: Reverse your name

```
let name = "Satya";

let reversedName = name.split("").reverse().join("");

console.log(reversedName);
```

Output:

```
aytaS
```

### Explanation (step by step)

1. `split("")` – Converts the string into an array of characters.
2. `reverse()` – Reverses the order of the characters.
3. `join("")` – Joins the characters back into a string.
4. `console.log()` – Prints the reversed string.

### Interview-friendly approach (without using built-in reverse)

```
let name = "Satya";
let reversedName = "";

for (let i = name.length - 1; i >= 0; i--) {
    reversedName = reversedName + name[i];
}

console.log(reversedName);
```

Output:

```
aytaS
```

How to explain in an interview:

"I take the string and initialize an empty string. Then I use a `for` loop starting from the last character and move backwards to the first character. I append each character to the empty string and print the reversed string."

Interview tip: Practise the `for` loop approach because interviewers may ask you to reverse a string without using built-in methods.
